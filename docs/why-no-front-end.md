# Why the analyst desk has no front end

The working records are reports, indicators, intelligence questions, assessments, actions and notes. A coding agent reads them through one CLI and writes only the operator's supplied facts. Read-only HTML shows the morning queue, coverage and overdue actions. Assessment dossiers preserve the source evidence and sharing instructions.

A screen provides shared sign-in, mobile access, live collaboration, drag and drop and interactive graph exploration. This base does not provide those. It also does not collect intelligence feeds, enrich indicators, monitor the dark web, generate vendor Insights Cards, or send alerts. It accepts already-authorised exports and supports the analyst's decisions about them. Feedly's collection service is a separate capability.

`npm run view` writes private HTML to views/. `npm run docs` writes private dossiers to docs-out/. Open them locally or print a dossier to PDF. No web server, hosting, editing form or published page is created. Offline operation covers the local records after dependencies are installed. The agent itself may need an internet connection.
